# Financial Morning Brief

面向国内金融市场的中文早报生成 Skill。用于稳定生成每日金融市场早报，重点分析隔夜全球市场、商品、汇率、利率、央行政策、地缘政治、企业财报和行业事件对 A股、中国香港市场、人民币、债市与商品期货的影响。

## 为什么需要它

- 每日早报容易因为临时新闻不同而结构漂移，导致复盘和阅读体验不稳定。
- 金融早报需要同时覆盖指数表现、商品汇率、成交额趋势和核心事件，缺一项都会影响判断。
- 影响度如果同时存在“小数系数”和“10分制”会造成口径冲突。
- 市场分析必须用具体数字和来源链接，不能只写模糊判断。

本技能把早报产出固定为一套可复用流程：先收集市场数据和过去 24 小时重大事件，再按对国内市场的影响排序，最后输出结构稳定、数字具体、来源可追溯的中文报告。

## 固定输出结构

每次生成早报时，默认保持以下顺序：

1. 核心结论
2. 全球主要市场收盘速览
3. 大宗商品、汇率与利率
4. A股上个交易日成交额与趋势评估
5. 按影响度排序的核心事件
6. 今日关注与交易框架
7. 来源

## 核心规则

- 报告标题：`【YYYY年M月D日】金融市场早报`
- 默认文件名：`早报-YYYY-MM-DD.html`
- 影响度只使用 10 分制：`10/10`、`9.5/10`、`8/10`
- 不再使用单独的“小数影响系数”
- 所有重要涨跌幅、金额、概率、利率、成交额都必须写具体数字
- 每条核心事件必须附来源链接
- 前 2-3 条高影响事件详细展开，中间事件中等描述，低影响事件简写
- 金融颜色遵循中国市场习惯：上涨红色，下跌绿色

## 数据覆盖

### 市场指数

- A股：上证指数、深证成指、创业板指、科创50或沪深300
- 中国香港：恒生指数、恒生科技指数
- 美国：道指、标普500、纳指、费城半导体指数
- 亚太：日经225、韩国KOSPI
- 欧洲：德国DAX、法国CAC、英国富时或欧洲斯托克50

### 商品、汇率与利率

- 原油：WTI、Brent
- 贵金属：现货黄金或 COMEX 黄金、白银
- 工业金属：铜、铝等
- 汇率：美元指数、在岸/离岸人民币、美元/日元
- 债券：10Y 美债收益率，必要时补充 2Y/30Y 美债和中国国债收益率

### 事件类型

- 美联储、欧央行、日本央行和中国央行政策
- 美国通胀、就业、PMI、GDP 等宏观数据
- 地缘政治和能源运输风险
- 半导体、AI、能源、金融、港股科技等关键行业事件
- 重要公司财报、回购、融资、IPO、监管政策
